CENTRAL MULTIMIDIA TV BOX - PROJETO ANDROID

Projeto preparado para Android TV / TV Box.

Recursos nativos incluídos:
- Interface HTML em WebView
- Modo paisagem e tela cheia
- Internet HTTPS e HTTP liberados
- Volume geral do Android
- Lista de aplicativos instalados
- Adicionar aplicativos à central pelo HTML
- Abrir aplicativos instalados
- YouTube dentro da WebView
- Rádio online

Para gerar o APK:
1. Abra esta pasta no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Menu Build > Build APK(s).
4. O APK será gerado em app/build/outputs/apk/debug/app-debug.apk

Pacote: com.pitstop.centralmultimidia
Versão: 1.0
Min Android: 6.0 (API 23)

BUILD ONLINE PELO GITHUB ACTIONS
--------------------------------
Este pacote inclui .github/workflows/gerar-apk.yml.
Depois de enviar o conteúdo para um repositório GitHub, abra Actions > Gerar APK TV Box > Run workflow.
Ao terminar, baixe o artifact "Central-Multimidia-TVBox-APK".
Consulte COMO_GERAR_APK_NO_GITHUB.txt para o passo a passo completo.
